# Spring AI Support Assistant

An existing Spring Boot application that will gradually evolve
to explore how AI capabilities can be integrated into a
traditional Java/Spring application.

## Objective

The goal is not to build an AI application from scratch.

Instead, this project starts with a traditional Spring Boot
application and explores how AI can be introduced incrementally
while keeping existing business logic, services and application
architecture intact.
